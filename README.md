## SciTeX Ecosystem (https://scitex.ai)
100% Opensource Research Platform

- [**SciTeX-Cloud**](https://github.com/SciTeX-AI/scitex-cloud) Django source code of the cloud platform for SciTeX System (https://scitex.ai)
- [**SciTeX-Local**](https://github.com/SciTeX-AI/emacs-claude-code) Human-in-the-environment platform for collaboration with LLM agents using Emacs
- ~~[**SciTeX-Scholar**](https://github.com/SciTeX-AI/scitex-code/tree/main/src/scitex/scholar) Literature Search, Reference Manager, Knowledge Gap Identification, and Hypotheses Generation~~
  - Integrated into `scitex-code` (https://github.com/SciTeX-AI/scitex-code/tree/main/src/scitex/scholar)
- [**SciTeX-Code**](https://github.com/SciTeX-AI/scitex-code) Standardized and reusable Python scripts for scientific workflows
- [**SciTeX-Viz**](https://github.com/SciTeX-AI/scitex-viz) Python wrapper for SigmaPlot for publication-ready quality of graphing
- [**SciTeX-Writer**](https://github.com/SciTeX-AI/scitex-writer) Organized LaTeX compilation system with predefined directory structures and caption handling
