## This repository is not the SciTeX profile page

The page that describes SciTeX — what it is for, what to run first, which
repositories carry it — is the organisation's profile repository, and it renders
at **[github.com/scitex-ai](https://github.com/scitex-ai)**:

**[`scitex-ai/.github` → `profile/README.md`](https://github.com/scitex-ai/.github/blob/main/profile/README.md)**

This repository is kept only because it is where that page started, before it
moved. It has one file, last edited **2025-10-18**, describing a layout that no
longer exists: of the six links it carried, **three returned `404`** when checked
on **2026-09-17** — `SciTeX-AI/scitex-code`, `SciTeX-AI/scitex-code/tree/main/
src/scitex/scholar`, and `SciTeX-AI/scitex-viz`.
